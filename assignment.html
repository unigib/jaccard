Assignment: Document Plagiarism Checker App

Introduction to Algorithms | Implementation: Python (Tkinter or Flask) + AI Coding Assistant

Core Algorithm N-Grams & Jaccard Set Similarity
UI Framework Tkinter Desktop or Flask Web
AI Usage Allowed (Gemini / ChatGPT)

1. The Problem

How do tools like Turnitin decide if a student's essay copied someone else's work? Checking for 100% word-for-word identical documents is too easy to beat (changing just one word fools a direct match). Instead, plagiarism engines look for overlapping sequences of words.

Your goal is to build an application that scans an incoming document against a folder of existing articles and flags whether the text is suspicious, along with an overall similarity percentage.

2. The Algorithm Explained (Step-by-Step)

You can generate this logic using Gemini or any LLM, but you must understand every stage:

Step A: Text Normalization (Cleaning)

Strip out punctuation and convert all text to lowercase so capitalization and commas don't fool your detector.

Step B: Word N-Grams (Chunking)

Break text into sliding sequences of N consecutive words (usually N = 3, called "trigrams").

"The quick brown fox jumps" → {"the quick brown", "quick brown fox", "brown fox jumps"}
Step C: Jaccard Similarity Calculation

Compare the set of chunks in Document A with the set in Document B using set intersection and union:

Similarity = (Shared Chunks) / (Total Unique Chunks in Both) × 100%

If similarity is greater than 30% (or your chosen threshold), flag the document as Potential Plagiarism.

3. What Your App Needs to Do

  • Database/Folder of References: A /corpus folder with at least 5 plain text files (e.g., sample articles, encyclopedia paragraphs, or sample essays).
  • Input Interface: A clean Tkinter window or web page (Flask) with a large text box where a user can paste a paragraph or load a file.
  • Run Check Button: Compares the pasted text against all files in the reference folder.
  • Clear Results Display:
    • Show which document had the highest match.
    • Display the Similarity Score (e.g., "42% Match with article_2.txt").
    • Display a clear Status Badge: Original or Suspect Plagiarism.
    • Bonus: Highlight or list the exact 3-word phrases that were copied.

4. How to Use AI (Gemini / ChatGPT) for this Task

Do not just ask the AI: "Build me a plagiarism app." The output will be messy and hard to debug. Instead, break it into 3 targeted prompts:

Prompt 1 (The Algorithm):
"Write a Python function that takes two strings, cleans them, breaks them into 3-word n-grams, and calculates their Jaccard similarity percentage using Python sets."
Prompt 2 (The Multi-file Scanner):
"Write a function that takes a query text string and compares it against all .txt files inside a folder called 'corpus', returning the filename and percentage of the highest match."
Prompt 3 (The UI):
"Wrap this logic in a simple [Tkinter / Flask] interface that has a text input box, a 'Check Plagiarism' button, and displays the result with a red or green alert."
